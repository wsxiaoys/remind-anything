# Iteration 3 Feedback

This document tracks the feedback items for the third iteration.

## Items

### 1. Inappropriate layout when view is resized (e.g., full screen view)
* **Problem**: When the app window is resized or put into full screen, the detail view is not appropriately layouted. Specifically, the captured screenshot image inside the reminder details scales up excessively and gets cropped or behaves poorly, making the layout look unoptimized and giant.

* **Screenshot 2 (Resized / Full screen view)**: ![Resized View](assets/screenshot-2.png)

### 2. Undesirable action buttons layout
* **Problem**: The layout of the action buttons ("Remind later", "Complete", "Archive", "Delete") at the bottom of the detail view is undesirable, especially when the window is resized or the layout changes, causing the buttons to stretch excessively across a 2x2 grid.
